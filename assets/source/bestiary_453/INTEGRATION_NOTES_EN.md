# Caelum Argenteum — recovered folklore reference pack

This package supplies all 58 final concept PNGs recovered from the October 20, 2026 delivery for [issue #453](https://github.com/damiancurti/Caelum-Argenteum/issues/453). The PNG bytes are preserved. The Tejú Jaguá reference uses seven canine heads and replaces the earlier reptilian-head image.

The catalogue is reconstructed from the previously approved table, not recovered from the original ZIP manifest. Image assignments were reconstructed using descriptive filenames, visible anatomy and sequence. Original filenames and SHA-256 values remain available for review. The original prompts and original index were not recovered.
