## Reproduction and compatibility

Run `python assets/validation_548/prepare.py --directory <fresh-name>`, then:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File assets/validation_548/run_native.ps1 -Directory <fresh-name> -Label dialogue-01 -Fixture socialization.pk3 -Script dialogue.cfg -Map MAP01
```

Use MAP01 for actual quest responses. Save/load scripts use `-LoadGame
socialization.zds` or `active.zds`; hub.cfg starts on MAP99. The optional
prepare_compat.py copies original saves before testing upgrade or rollback;
its rollback bridge belongs only with 5.4.7, never the new runtime. Supply the
preserved baseline runtime and source fixture directory. Keep original saves.
This tests a specific reversible baseline, not arbitrary older versions.
