Endpoint diagnosis reproduction (#868)

Run from the repository root with Python and the installed GZDoom4.14.2/DOOM2
development dependency. Only the diagnostic sources/configuration/evidence are
retained here. Generated packages, map fixtures, saves and engine binaries stay
under build/ and are not distributed in this patch. Normal production keeps the
original shared endpoint implementation; canonical conclusions are in HISTORY.

Create each output in a new build/ directory. The runner refuses another active
gzdoom.exe, keeps the game unpaused in the background with5% audio, captures exit
status and rejects missing assertions/fatal markers/timeouts. Timeout can also
mean a native crash dialog that did not reach engine.log; do not count it as pass.
